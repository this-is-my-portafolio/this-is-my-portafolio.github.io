# Brumalia Telares — Landing editorial artesanal

**Proyecto conceptual de portafolio** para la marca **Just King**.
Taller textil artesanal ficticio, con datos inventados para demostrar diseño de landing warm/editorial para negocios de artesanía y decoración boutique.

## Stack

HTML5 + CSS3 + JavaScript vanilla · Google Fonts (Fraunces + DM Sans + Instrument Serif) · sin frameworks, sin build.

## Estructura

```
brumalia-telares/
├── index.html
├── css/styles.css
├── js/main.js
├── assets/                          (vacío — todos los "retratos" y "arte" son gradientes CSS)
├── README.md                        (este archivo, público)
├── docs/                            (documentación técnica interna)
│   ├── README.md · frontend.md · backend.md · prompts.md · LOG.md
└── datos-de-brumalia-telares/       (ficha ficticia de la marca)
    └── README.md · empresa.md · equipo.md · clientes.md · servicios.md
```

Documentación completa: ver [`docs/`](docs/README.md).
Datos ficticios utilizados: ver [`datos-de-brumalia-telares/`](portafolio/brumalia-telares/datos-de-brumalia-telares/README.md).

## Cómo verlo

Doble clic en `index.html`, o:

```bash
python -m http.server 8000
```

## Aviso

Marca, personas, clientes, teléfono, correo y datos numéricos son **ficticios**, creados para efectos de demostración.
